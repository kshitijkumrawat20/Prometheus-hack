# MasteryMap — 2-Minute Demo Video Script

**Target Duration:** 1:50–2:00 max (Judges evaluate quickly).

---

## Script Breakdown

| Time | Visual / Screen Action | Voiceover Script |
|---|---|---|
| **0:00–0:15** | Title Card / Opening on student drilling random questions on standard flashcard app. | *"Students plateau not because they don't study, but because they drill randomly instead of targeting their actual weak prerequisites. Traditional apps guess; MasteryMap measures."* |
| **0:15–0:30** | Paste syllabus into MasteryMap upload page and click "Generate Knowledge Graph". | *"Watch how it works. We paste any course syllabus or chapter outline — here's Algebra I. In seconds, Gemini parses the concepts and prerequisite dependencies into an interactive knowledge graph."* |
| **0:30–1:00** | Transition to the Learning View. Click on the targeted concept ("Properties of Numbers"). Submit an answer. | *"MasteryMap automatically targets the weakest unlocked node — in this case, fundamental properties of numbers. As I answer questions, a Bayesian Knowledge Tracing model updates my real mastery probability step by step."* |
| **1:00–1:30** | Submit a wrong answer to show the explanation card, then answer a prerequisite correctly. Show node color shift from Red → Amber → Green. | *"If I get a question wrong, Gemini provides a targeted explanation. But look at the graph — as I practice, node colors transition in real time from red to emerald green as my measured mastery crosses the 85% threshold, unlocking advanced concepts downstream."* |
| **1:30–1:50** | Show Summary View and full illuminated knowledge graph. | *"Under the hood, this isn't prompt vibes — it's real statistical inference with 4-parameter BKT. The student sees their understanding light up in real time. Thank you!"* |

---

## Key Highlights to Mention in Video
1. **Real ML/Statistical Inference**: BKT math model (not simple prompt guessing).
2. **Prerequisite Unlocking**: Weakest unlocked node selection.
3. **Visual Feedback**: Real-time graph node color/size animation.
